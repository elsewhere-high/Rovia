# McLaren preview asset

`mclaren.glb` is derived from the user-provided `mc-laren.zip` archive. The
source archive did not contain a license file. The model was optimized locally
with glTF-Transform (Draco compression, scene flattening, draw-call joining,
and a centered pivot) before being served by the application.

On 2026-10-13, the project owner confirmed that public distribution of this
model with Rovia is authorized. The archive did not include a separate license
text; this note records that confirmation and does not assign the project's
AGPL license to the model or grant additional standalone reuse rights.
